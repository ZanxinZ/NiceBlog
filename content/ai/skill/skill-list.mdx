## 前端设计

| 名称 | 用途 | 适用场景 |
| --- | --- | --- |
| `design-taste-frontend` | 反「AI 模板感」的前端设计：先读需求、推断设计方向，再产出不套模板的界面（v2，实验版） | 落地页、作品集、改版 |
| `design-taste-frontend-v1` | 上面那个 Skill 的 v1 原版，保留旧行为 | 依赖 v1 输出效果的老项目 |
| `minimalist-ui` | 编辑风格的极简界面：暖色单色、字重对比、扁平 Bento 网格，不用渐变和重阴影 | 内容型网站、博客 |
| `high-end-visual-design` | 规定字体、间距、阴影、卡片和动效，让页面有高级设计工作室的质感 | 品牌官网、营销页 |
| `industrial-brutalist-ui` | 瑞士印刷排版 + 终端风格的粗野主义界面，网格严格、字号对比强烈 | 数据看板、个性作品集 |
| `gpt-taste` | 强调 GSAP 滚动动效、AIDA 页面结构和无缝 Bento 网格 | 动效丰富的营销页 |
| `redesign-existing-projects` | 先审查现有站点的「AI 模板感」问题，再在不破坏功能的前提下升级设计 | 老网站改版 |
| `stitch-design-taste` | 为 Google Stitch 生成 `DESIGN.md` 设计规范 | 用 Stitch 出设计稿 |

## 图像与视觉稿

| 名称 | 用途 | 适用场景 |
| --- | --- | --- |
| `image-to-code` | 先生成设计图、分析后再按图实现网页 | 视觉要求高的网页开发 |
| `imagegen-frontend-web` | 生成网页设计参考图，每个页面区块单独一张横图 | 落地页视觉方案 |
| `imagegen-frontend-mobile` | 生成 App 界面概念图，默认放在手机外框里展示 | iOS / Android 界面构思 |
| `brandkit` | 生成品牌规范板：Logo 体系、识别系统、视觉提案 | 品牌 / 产品视觉定调 |
